# M12L19 - PRACTICE

## PART I - CREATE NEW AUTHOR

Use this API endpoint (`POST /authors`) to test data validation for creating a new author.

- Create a new API test that checks if it's possible to create an author when `firstName` and `lastName` are **exactly 3 characters long**.
- Create another test to check if it's possible to create an author when `firstName` and `lastName` are **exactly 128 characters long**.

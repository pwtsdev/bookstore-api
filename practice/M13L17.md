## PART I - GENERATE RANDOM BOOK PAYLOAD

For testing book-related functionality, you’ll need to generate books associated with an author.
To do this, implement a helper function like this:

```ts
export function getRandomBookPayload(authorId?: number): BookPayload {
  return {};
}
```

What does this function do?
Accepts an optional authorId and returns a payload to create a book.

If authorId is provided, it adds it to the authors array.

The rest of the data (title, year, price, available) is either static or randomly generated (e.g., getRandomTitle() should return a random string).

Use this function in your tests to dynamically generate books with an assigned author.
